# Global-Mortality-Tableau-Dashboard

## Overview
This project analyzes global mortality data to identify trends across countries and age groups. 
The goal is to highlight differences between total deaths and per capita death rates to support
more accurate data interpretation.

## Tools Used
- Tableau

## Dashboard Features
- Interacting visualizations by country and age group
- Comparison of total deaths vs. per capita death rates
- Filters to explore trends across regions and demographics
